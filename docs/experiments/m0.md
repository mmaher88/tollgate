# M0 experiments

Record the date, iOS version, CI run ID and outcome for each. Commands run from the repo root.

## E6: install a CI-signed build from Linux

1. `tooling/scripts/fetch-ipa.sh` (downloads `build/ipa/Tollgate.ipa`).
2. Connect and unlock the iPhone, then `tooling/scripts/install.sh`.
3. If iOS reports that Developer Mode is required: Settings > Privacy & Security > Developer Mode > On, reboot, confirm.
4. Launch Tollgate. Pass: the "Rust core in the app" section shows version 0.1.0 and "pong: app".

Result: pass. 2026-09-25, iPhone 15 Pro Max, iOS 27.0, CI run 36165304919 (Xcode 27.0, iOS 27.0 SDK). `pymobiledevice3 apps install` succeeded over USB. The app would not open until Developer Mode was enabled (Settings, Privacy & Security, Developer Mode, restart, Turn On). The app showed version 0.1.0 and "pong: app".

## E1: packet tunnel starts

1. In a terminal: `tooling/scripts/logs.sh`.
2. In the app tap Start; allow the "Add VPN Configurations" prompt; tap Start again if needed.
3. Pass: a `startTunnel core=0.1.0 ping=pong: tunnel ...` line and a `tunnel up` line from TollgateTunnel, the VPN indicator appears, status shows On, and "Shared container" shows the heartbeat after Refresh.

Result: pass. `startTunnel` and `tunnel up` logged by TollgateTunnel, status On, VPN indicator shown, heartbeat visible in the app, so the App Group container is shared.

## E3: extension memory limit

1. `tooling/scripts/logs.sh tunnel`.
2. With the tunnel on, tap "Probe memory".
3. Record the last `probe step=... allocated_mib=... available=...` line before the process exits. Pull the jetsam report with `tooling/scripts/device.sh crash pull build/crashes` and search it for `TollgateTunnel`.

Result (limit in MiB): 50 MiB.

| Point | `os_proc_available_memory()` |
|---|---|
| Fresh extension start | 49,936,784 bytes (47.6 MiB) |
| After 44 MiB allocated (step 11) | 3,307,872 bytes |
| Step 12 (48 MiB) | never logged; the process was killed |

Each 4 MiB step consumed about 4.21 MB. This is consistent with a 50 MiB (52,428,800 byte) limit and a baseline footprint of about 2.4 MiB for the Swift extension before the Rust core does any work. No JetsamEvent report was written for this per-process kill; the streamed log is the evidence.
